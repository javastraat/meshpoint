MESHPOINT

An open-source Meshtastic base station that turns a $40 retired crypto-miner board into a six-network mesh radio dashboard — no phone app, no cloud required.

EINSTEIN TECHINC AGPL-3.0

What it is

Everything a repeater sees, from a browser tab.

Most mesh nodes only know their own traffic. Meshpoint pairs a real LoRa concentrator with a full web dashboard — so you get every packet in range, native TX/RX, and a chat UI that needs nothing installed on your phone.

  • Observer, not just participant — sees everything in range, not only what's addressed to it.
  • Native transmit — same sync word and encryption as the mesh, so nodes see it as a regular participant.
  • Runs on retired hardware — Helium miner boards nobody wanted anymore.

Origin story

Built by KMX415, out of Helium's leftovers.

When Helium's IoT mining network didn't pan out, it left a huge surplus of SX1302/SX1303 LoRa concentrator hardware — RAK Hotspot V2s, SenseCap M1s — sitting on eBay for $30–60. KMX415 saw a repurposing opportunity: that hardware could run a proper Meshtastic base station instead of gathering dust.

Meshpoint started as exactly that — a way to point retired mining boards at a mesh network instead of a blockchain.

This deployment

What we've added on top.

Running as a fork tuned for a SenseCap M1 and a browser radio receiver — tracking upstream, shipping a real second layer alongside it.

  • A whole plugin platform, not just plugins — built the extensibility itself: 18 plugins (the RTL-SDR family, DAPNET, Reticulum), a community plugin-source installer, and 18 drop-in themes with a live builder. Turned one app into a platform.
  • Reticulum grown into a full ecosystem — from messaging to real-time voice calls, photo and paper-QR messages, a multi-tab NomadNet browser with forms/downloads/identity fingerprinting, propagation relaying, and telemetry.
  • Field-ops hardware tooling + hardening — flash Meshtastic/MeshCore/pager firmware straight from the dashboard, RF spectrum scanning working on the SenseCap M1 specifically (upstream marks it unavailable on that board), MeshCore repeater monitoring, offline maps, and filesystem-only security opt-ins closing real self-escalation gaps.
